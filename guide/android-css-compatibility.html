Android 5.0 ~ 최신 호환 CSS 크로스 브라우징

안드로이드 OS 버전별 CSS 호환성 비교 표

안드로이드 OS 5.0(Lollipop, 초기 WebView Chromium 37) 환경과 최신 안드로이드(Android 14/15+, 최신 Chromium 엔진) 환경을 동시에 지원해야 하는 하이브리드 앱 및 모바일 웹 작업 시, 공통으로 안전하게 사용할 수 있는 CSS와 버전별 미지원으로 폴백(Fallback)이 필수적인 CSS를 구분하여 제공합니다.

✅ 공통 사용 가능 (Safe)

Box-sizing, 기본 Flexbox(1차원 정렬), 2D Transform, Transition, Border-radius, Box-shadow, Rem/Em 단위, 미디어 쿼리 등은 안드로이드 5.0부터 최신까지 온전히 안전하게 작동합니다.

❌ 공통 사용 불가 (대체 필수)

CSS 변수 (var()), CSS Grid (display: grid), Flexbox gap, aspect-ratio, backdrop-filter, :has() 등은 안드로이드 5.0에서 렌더링되지 않으므로 반드시 대체 코드를 작성해야 합니다.

⚠️ 주의 및 접두사 필요 (Prefix)

Flexbox 구형 문법, -webkit-transform, -webkit-line-clamp, -webkit-user-select 등은 -webkit- 벤더 프리픽스를 병기하거나 Autoprefixer 자동 빌드를 거쳐야 안전합니다.

CSS 속성 / 기능명 안드로이드 5.0
(Chrome 37)		 최신 안드로이드
(Android 14/15+)		 최초 지원 버전 설명 및 안드로이드 5.0 대체(Fallback) 전략
var(--name) CSS Custom Properties (변수) ❌ 미지원 ✅ 완벽 지원 Chrome 49+ (Android 7.0+) 안드로이드 5.0에서는 CSS 변수가 완전히 무시되어 스타일이 깨집니다.
대체 전략: 변수 앞에 고정된 폴백 값을 먼저 선언하거나 Sass/SCSS 빌드로 컴파일 변환.
color: #6c8fff; /* 5.0용 폴백 */
color: var(--accent-color);
display: grid CSS Grid Layout ❌ 미지원 ✅ 완벽 지원 Chrome 57+ (Android 7.1+) 안드로이드 5.0 웹뷰에서는 Grid 레이아웃이 전혀 렌더링되지 않습니다.
대체 전략: 공통 환경에서는 Flexbox나 백분율 너비(width: 25%) 기반으로 레이아웃을 작성하세요.
display: flex Flexbox 기본 레이아웃 ✅ 공통 지원 ✅ 완벽 지원 Chrome 29+ (Android 4.4+) 1차원 가로/세로 정렬(`justify-content`, `align-items`, `flex-wrap` 등)은 5.0부터 최신까지 모두 정상 작동합니다.
※ 구형 기기 안정성을 위해 -webkit-box / -webkit-flex 프리픽스 병기 권장.
gap (Flexbox 내) Flexbox 간격 제어 ❌ 미지원 ✅ 완벽 지원 Chrome 84+ (Android 11+) 가장 잦은 실무 버그 요인: 5.0 및 구형 안드로이드에서는 Flexbox 내 `gap`이 무시되어 아이템들이 여백 없이 다닥다닥 붙습니다.
대체 전략: margin: 8px 및 부모 컨테이너의 음수 마진(margin: -8px) 기법 사용.
position: sticky 스크롤 고정 포지셔닝 ❌ 미지원 / 버그 ✅ 완벽 지원 Chrome 56+ (Android 7.0+) 안드로이드 5.0에서는 sticky가 무시되어 일반 static으로 표시됩니다.
대체 전략: JS의 IntersectionObserver 또는 스크롤 이벤트로 클래스를 토글하여 position: fixed로 전환.
aspect-ratio 종횡비 고정 ❌ 미지원 ✅ 완벽 지원 Chrome 88+ (Android 11+) 안드로이드 5.0에서는 무시되어 높이가 0이 되거나 이미지가 찌그러질 수 있습니다.
대체 전략: 전통적인 padding-top: 56.25% (16:9 비율 유지) 트릭 사용.
backdrop-filter 배경 블러 (Glassmorphism) ❌ 미지원 ✅ 완벽 지원 Chrome 76+ (Android 10+) 배경 흐림 효과가 적용되지 않고 투명하게 관통됩니다.
대체 전략: 반투명 솔리드 배경색(background: rgba(15, 17, 23, 0.9))을 기본으로 제공.
box-sizing 박스 모델 기준 ✅ 공통 지원 ✅ 완벽 지원 Chrome 10+ (Android 4.0+) 패딩과 테두리를 너비에 포함시키는 border-box는 전 안드로이드 버전에서 100% 안전하게 공통 사용 가능합니다.
transform / transition 2D 변형 및 화면 전환 ✅ 공통 지원 ✅ 완벽 지원 Chrome 36+ (Android 4.4+) translate(), scale(), transition: all 0.3s 등은 모두 잘 지원됩니다.
※ 안드로이드 5.0의 GPU 가속 버그 방지를 위해 translateZ(0) 또는 will-change 점검 권장.
:has() / :is() / :where() 모던 의사 클래스 선택자 ❌ 미지원 (파싱 에러) ✅ 완벽 지원 Chrome 88~105+ 구형 브라우저에서 :has()를 사용하면 해당 CSS 규칙 블록 전체가 무효화됩니다.
대체 전략: 부모 상태 제어 시 자바스크립트로 부모 요소에 클래스를 부여하여 제어.
:focus-visible 키보드 전용 포커스 링 ❌ 미지원 ✅ 완벽 지원 Chrome 86+ (Android 11+) 5.0에서는 :focus-visible 규칙을 인식하지 못하므로 키보드 포커스 링이 사라질 수 있습니다.
대체 전략: 일반 :focus를 기본으로 주고 마우스 클릭 시 JS로 클래스를 제어하거나 focus-visible 폴리필 사용.
border-radius / box-shadow 둥근 모서리 및 그림자 ✅ 공통 지원 ✅ 완벽 지원 Chrome 4+ (Android 2.1+) 모든 안드로이드 버전에서 기본적으로 안정 지원됩니다. (단, 5.0 구형 웹뷰에서 overflow:hidden과 border-radius 동시 사용 시 클리핑 버그 주의)
CSS Nesting (중첩) 네이티브 CSS 중첩 구문 ❌ 미지원 ✅ 완벽 지원 Chrome 112/120+ Sass 없이 브라우저에서 직접 중첩하는 최신 표준 문법은 안드로이드 5.0에서 전체가 무시됩니다.
대체 전략: 일반적인 평면 BEM 클래스 구조로 작성하거나 빌드 도구(PostCSS 등)를 통해 컴파일하여 배포.
rem / @font-face (WOFF, TTF) 웹 폰트 및 상대 단위 ✅ 공통 지원 ✅ 완벽 지원 Chrome 4+ (Android 4.0+) rem 단위 및 WOFF/TTF 폰트는 5.0부터 완벽하게 작동합니다. (단, 최신 WOFF2 포맷은 Chrome 36+ 지원으로 5.0에서 일부 제한될 수 있으므로 WOFF/TTF 폴백 병기 권장)
-webkit-line-clamp 멀티라인 텍스트 말줄임 (...) ⚠️ 접두사 필수 ✅ 완벽 지원 Chrome 14+ 3대 필수 속성 세트(display: -webkit-box; -webkit-box-orient: vertical; overflow: hidden;)를 완벽하게 기재해야 5.0에서도 말줄임이 정상 동작합니다.

🛠️ 안드로이드 5.0 ~ 최신 OS 공통 작업 실무 3대 수칙

1. @supports 기능 쿼리 활용

모던 CSS 속성을 사용할 때는 @supports (gap: 10px) { ... }로 감싸서 지원 브라우저에만 고도화 스타일을 주고, 기본 스타일은 마진(margin) 기반으로 작성합니다.

2. PostCSS & Autoprefixer 파이프라인

최신 CSS 문법을 작성하더라도 빌드 시점에 browserslist: ["android >= 5"] 옵션을 주어 자동으로 구형 벤더 프리픽스를 주입하고 변수를 정적 색상으로 트랜스파일합니다.

3. 안전한 폴백(Cascading Fallback) 순서

항상 구형 브라우저용 고정 값(예: color: #333;)을 먼저 선언하고, 그 다음 줄에 최신 문법(예: color: var(--text-color);)을 작성하여 점진적 향상을 구현합니다.

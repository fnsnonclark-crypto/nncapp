웹 표준 코딩 기초 가이드 (Web Standards)

웹 표준(Web Standards)은 W3C(World Wide Web Consortium) 등의 국제 기구가 제정한 권고안으로, 어떤 브라우저나 운영체제, 디바이스에서도 동일한 정보와 기능을 제공할 수 있도록 지원하는 웹 개발의 기본 원칙입니다.

🏗️
Structure (HTML5)

구조 (HTML)

웹 문서의 뼈대를 구성하며, 시맨틱 태그를 통해 문서의 의미와 계층 구조를 명확하게 정의합니다.

🎨
Presentation (CSS3)

표현 (CSS)

레이아웃, 색상, 타이포그래피, 반응형 스타일 등 시각적 디자인 요소를 HTML과 분리하여 제어합니다.

⚡
Behavior (JavaScript)

동작 (JavaScript)

사용자 인터랙션, 동적 UI 제어, 비동기 통신 등 이벤트와 데이터 로직을 독립적으로 처리합니다.

🔍

1. 시맨틱 마크업 (Semantic HTML5)

의미 있는 태그를 사용하여 문서의 구조와 목적을 명확히 정의
HTML5 Layout

시맨틱 레이아웃 구조 태그 사용

과거 <div class="header">처럼 의미 없는 div 태그로만 레이아웃을 잡던 방식 대신, HTML5의 시맨틱 태그(header, nav, main, section, article, aside, footer)를 사용하여 문서의 역할을 선언해야 합니다.

핵심 사용 규칙

  • <main>: 페이지당 단 1개만 존재해야 하며 본문의 고유 콘텐츠 영역을 지정
  • <section>: 주제별로 묶인 콘텐츠 그룹이며 통상 제목(h2~h6)을 포함
  • <article>: 독립적으로 배포되거나 재사용될 수 있는 완결된 콘텐츠(블로그 글, 뉴스 카드 등)
  • <nav>: 주요 내비게이션 링크 모음 (모든 링크가 아닌 주요 메뉴에 사용)
✕ 비표준 / 구형 마크업 (Div Soup)
<div id="header">
  <div class="menu">...</div>
</div>
<div id="contents">...</div>
<div id="footer">...</div>
✓ 웹 표준 시맨틱 마크업
<header>
  <nav aria-label="메인 메뉴">...</nav>
</header>
<main>
  <section>...</section>
</main>
<footer>...</footer>
Headings

논리적인 제목(Heading) 계층 구조 (h1 ~ h6)

제목 태그는 글자 크기를 조절하는 용도가 아니라, 문서의 목차(Outline)와 계층 관계를 나타내는 구조 태그입니다. 순차적으로 단계를 건너뛰지 않고 사용해야 합니다.

핵심 사용 규칙

  • <h1>: 페이지 전체를 대표하는 가장 중요한 단 1개의 제목으로 사용 권장
  • <h2> → <h4>처럼 계층 단계를 건너뛰지 않고 순차 구성
  • 글자 크기는 CSS의 font-size로 조절하며 태그 자체를 스타일 목적으로 변경하지 않음
Text Elements

의미를 갖는 텍스트 태그의 올바른 구분

시각적인 모양뿐만 아니라 스크린 리더와 검색엔진에게도 의미를 전달할 수 있도록 태그의 성격에 맞게 구분해 작성합니다.

태그별 차이점

  • <strong>: 콘텐츠의 **중요성/심각성**을 강조 (스크린리더 강조 음조) vs <b>: 단순 시각적 굵은 글씨
  • <em>: 문맥상 **강조하는 어조** 전달 vs <i>: 전문 용어, 외국어 등 단순 기울임체
  • <time datetime="2026-09-21">: 기계가 판독할 수 있는 날짜/시간 마크업

2. 기본 문법 및 유효성 (W3C Validation)

브라우저 렌더링 엔진이 오류 없이 해석할 수 있는 엄격한 문법 규칙 준수
Document Setup

DOCTYPE 선언 및 문서 기본 설정

HTML5 표준 모드(Standards Mode) 렌더링을 위해 문서 최상단에 <!DOCTYPE html>을 선언하고, 올바른 인코딩 및 주 언어를 명시해야 브라우저의 비표준 쿼크 모드(Quirks Mode) 동작을 방지할 수 있습니다.

✕ 비표준 / 누락 예시
<!-- DOCTYPE 및 언어, 인코딩 누락 -->
<html>
<head>
  <title>My Page</title>
</head>
✓ 표준 문서 기본 구조
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>표준 문서 제목</title>
</head>
Syntax Rules

태그 닫힘, 중첩 규칙 및 ID 유일성 보장

마크업 문법 오류는 브라우저의 DOM 트리 파싱 실패, 스타일 깨짐, 스크립트 오작동을 유발하므로 표준 문법을 철저히 준수해야 합니다.

실무 필수 문법 체크리스트

  • 모든 태그명과 속성명은 **소문자**로 작성 (예: <div class="...">)
  • 모든 속성값은 **따옴표(큰따옴표 권장)**로 감싸기 (예: id="main")
  • 열린 태그는 반드시 닫아야 하며, 엇갈려 중첩 금지 (예: <p><b>내용</b></p>)
  • 한 페이지 내에서 동일한 id 속성값 중복 절대 금지 (ID는 유일한 식별자)
  • 인라인 요소(<a>, <span>) 안에 블록 요소를 무분별하게 중첩하지 않기
Separation of Concerns

인라인 스타일(style) 및 이벤트(onclick) 배제

HTML 태그 내에 직접 style="color: red;"나 onclick="doSomething()"을 작성하면 구조와 표현/동작이 뒤섞여 유지보수성이 급격히 저하되고 웹 보안 정책(CSP)에 위배될 수 있습니다.

✕ 인라인 혼합 (지양)
<button style="color:red; font-size:14px;" 
        onclick="alert('클릭')">
  버튼
</button>
✓ CSS 클래스 및 addEventListener 분리 (권장)
<!-- HTML -->
<button class="btn-danger" id="myBtn">버튼</button>

<!-- JS -->
document.getElementById('myBtn')
  .addEventListener('click', handler);

3. 반응형 웹(RWD) 및 모던 CSS 표준

다양한 화면 해상도와 디바이스 환경에 유연하게 대응하는 스타일링 원칙
Responsive Core

뷰포트 메타태그 및 유연한 상대 단위(rem, %) 사용

모바일 기기에서 올바른 배율로 렌더링되도록 viewport 메타태그를 필수로 적용하고, 고정 px 단위 대신 사용자의 글꼴 크기 설정에 대응할 수 있는 rem 단위를 기본으로 사용합니다.

단위 권장 기준

  • 글꼴 크기(font-size) 및 여백(padding/margin): 루트 기준 상대 단위인 rem 사용 권장
  • 너비(width): 유연한 비율 단위인 %, fr, vw 활용
  • 고정 픽셀(px)은 미세한 보더(1px border)나 고정 아이콘 크기 등에만 제한적 사용
Modern Layout

Flexbox와 CSS Grid를 활용한 표준 레이아웃

과거의 float과 clearfix 핵, 또는 table을 이용한 레이아웃 방식은 현대 웹에서 지양되며, 1차원 배치는 Flexbox, 2차원 그리드는 CSS Grid를 사용하는 것이 표준입니다.

Media Queries

모바일 우선(Mobile-First) 미디어 쿼리 설계

기본 스타일을 모바일(소형 화면) 기준으로 먼저 작성하고, 화면이 넓어질수록 @media (min-width: 768px) 형태로 점진적 향상(Progressive Enhancement)을 적용하는 것이 성능 및 유지보수에 유리합니다.

4. 크로스 브라우징 & 성능/보안 표준

다양한 브라우저 환경 호환성과 쾌적한 웹 성능 보장
Performance

표준 이미지 최적화 및 지연 로딩 (loading="lazy")

뷰포트 밖에 위치한 이미지에 브라우저 기본 지원 속성인 loading="lazy"를 지정하여 초기 로딩 속도와 데이터 트래픽을 크게 절감할 수 있습니다.

✓ 지연 로딩 및 반응형 이미지 표준
<img src="hero-small.webp"
     srcset="hero-small.webp 480w, hero-large.webp 1200w"
     sizes="(max-width: 600px) 480px, 1200px"
     alt="프로젝트 소개 배너"
     loading="lazy"
     decoding="async"
     width="1200" height="600">
✓ 차세대 포맷 picture 태그
<picture>
  <source srcset="banner.avif" type="image/avif">
  <source srcset="banner.webp" type="image/webp">
  <img src="banner.jpg" alt="이벤트 안내">
</picture>
Web Forms

표준 폼 컨트롤과 적절한 Type 및 레이블 매핑

모바일 가상 키보드와 브라우저 자동 완성 기능을 극대화하기 위해 입력 서식에 맞는 적절한 type(email, tel, number 등)과 autocomplete 속성을 지정하고 <label>을 반드시 연결합니다.
